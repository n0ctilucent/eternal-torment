# graphers 🎃📟 — TI Calculator RAM Visualization

HTML-based RAM visualization tools for TI-83 and TI-85 calculators. These generate HTML files that display calculator memory layout as rendered graphics.

## Contents 👁️

| Directory/File | Purpose |
|---------------|---------|
| `index.html` | Main entry point — hosts the visualization interface |
| `ram.html` | Full RAM layout rendering (generic) |
| `partial.html` | Partial/incremental RAM display mode |
| `TI-83/ram.html` | TI-83 specific memory map |
| `TI-85/ram.html` | TI-85 specific memory map |

## Usage 🔧

Open any `.html` file directly in a browser. These are standalone — no server required. They were designed to visualize calculator memory dumps for the `src/spinning-cube/` and related graphics projects.
