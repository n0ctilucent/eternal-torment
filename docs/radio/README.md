# radio 📡👻 — Radio Protocol Notes

Documentation for three radio protocol implementations:

| File | Protocol | Description |
|------|----------|-------------|
| `adsb_1090.txt` | ADS-B 1090 MHz | Aircraft Automatic Dependent Surveillance-Broadcast signal analysis | 🛫
| `baofeng1.txt` | Baofeng Radio | Baofeng handheld transceiver configuration and usage notes |
| `pocsag.txt` | POCSAG | Paging protocol documentation for pager message encoding/decoding | 📟

These are reference docs — not executable code. See the main repo README for related projects in `src/`.
