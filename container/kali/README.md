# container/kali 🐉🧟 — Kali Linux Base Container

Builds a Kali Linux-based container image for development and CTF work.

## Build

```sh
podman build -t eternal-torment-kali . || docker build -t eternal-torment-kali .
```

Uses `Containerfile` (Dockerfile format). This is one of two base images in this directory — see [../README.md](../README.md) for the full container setup including networking.
